## 我准备用它来做什么

- 练习：改文件 -> 提交（commit）-> 推送（push）
- 用分支（branch）做实验，不影响主代码
- 用 Pull Request（PR）审查自己的改动

## Git 常用命令

| 命令 | 作用 |
| --- | --- |
| `git status` | 查看当前有哪些改动 |
| `git add .` | 把所有改动加入暂存区 |
| `git commit -m "说明"` | 提交到本地仓库 |
| `git push` | 把本地提交上传到 GitHub |
| `git pull` | 把 GitHub 上的新改动拉到本地 |
| `git log --oneline` | 查看提交历史 |
